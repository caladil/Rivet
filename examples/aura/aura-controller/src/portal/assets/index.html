General
{{DASH_TIMEZONE}}

Set on the machine, not here. Rivet projects the machine's timezone key to /etc/localtime, and both halves of Aura read that — so there is one answer to what time it is instead of two that can disagree. Change it with rivet apply edit timezone <zone> confirm.

Display
{{SCREENSAVER_FIELDS}}
TV / HDMI-CEC

Switching a television on and off is the machine's, not Aura's. A kiosk application holds the display lease exclusively and cannot reach /dev/cec, so Rivet keeps that device for itself and drives it from the machine document's [display] table (ADR-039 §3.1):

rivet apply edit display.off 19:00 confirm
rivet apply edit display.on 07:00 confirm

Both keys or neither — a machine told when to switch off and never when to switch on is a machine somebody has to visit.

Weather

The panel always shows the condition icon, outdoor temperature and humidity, the indoor column, and the NWS forecast statement. Enable weather turns all of it on or off together.

The National Weather Service asks every client for a way to reach its operator, so Aura sends this in each weather request. Leave it empty and requests name only Aura.
